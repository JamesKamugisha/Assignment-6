(1) The time command shows how long my program took to run. The real time was 0.011 seconds, which is the total time from start to finish. The user time was 0.009 seconds, which is the time the CPU spent running my code. The sys time was 0.002 seconds, which is the time spent on system operations.
(2) I did not notice any data races in my program. I gave each thread its own count and a place to store the matching lines. Once all the threads finished, I added their results together. This way, the threads were not trying to update the same count at the same time, so I did not need to use a mutex.
(3) With Pthreads, I had to create the threads using pthread_create() and wait for them using pthread_join(). With OpenMP, I used #pragma omp parallel for, which made that part easier. I still divided the file into smaller parts, but OpenMP handled the threads for me. I found OpenMP easier to use because it required less code for managing the threads.
